# Runtime Node Editor

A UI Node editor used in runtime applications for the purpose of visual programming.

Developed in order to develop other applications that require a UI Node Editor as a core requirement.

# Technologies Used

    • Unity
    • C#

# Architecture

Unity Runtime → Runtime Node Editor  → Unity UI

# Features

__Key Features__
- Spawnable Nodes
- Interactable UI Input Elements
- Consistent Grid Background
- Save States

__Other Features__
- Curvature Connection Lines
- Clean Node Execution

# Getting Started

To execute the pre-built project simply do the following:
    • Windows – Run RNE.exe
    • Linux – Run RNE.x86_64

To open the project Unity 2022.3.13 is required.

The following repositories are needed for the project to execute:
    • MattX101 Utils
